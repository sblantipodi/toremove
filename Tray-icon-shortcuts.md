With a desktop session and a supported tray, Firefly provides quick access to capture, settings, and profiles. On a host without a desktop, use the [web interface](https://github.com/sblantipodi/firefly_luciferin/wiki/Remote-Access) instead.

The Windows/AWT tray supports these mouse shortcuts. Linux indicator behavior depends on the desktop; use its menu for the available actions:
- **Single click:** open settings
- **Double click:** toggle capture (bias light ON/OFF)
- **Middle click:** toggle static light (LEDs ON/OFF, uses the color selected in the "Misc" tab)
- **Right click:** opens a popup menu where you can:
  - Access all the shortcuts above
  - Switch [aspect ratio](https://github.com/sblantipodi/firefly_luciferin/wiki/Aspect-ratio) on the fly
  - Select the desired [profile](https://github.com/sblantipodi/firefly_luciferin/wiki/Profiles)
  - Access the [info menu](https://github.com/sblantipodi/firefly_luciferin/wiki/Very-fast-capture) which shows useful information about your screen capture
  - Open the **Firefly web interface**
  - Check for updates through **Update**
  - Exit the app
